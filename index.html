Fundamentos da Web

Página Estática

Uma página estática é uma página cujo conteúdo é previamente definido e enviado pelo servidor da mesma forma para todos os usuários. Ela normalmente é desenvolvida com HTML e CSS e não precisa ser alterada durante a requisição do usuário.

Exemplo: uma página institucional simples de uma empresa.

Página Dinâmica

Uma página dinâmica é uma página cujo conteúdo pode ser gerado ou alterado de acordo com as informações solicitadas pelo usuário. Para isso, pode utilizar linguagens de programação no servidor, como PHP, Java ou JavaScript, além de bancos de dados.

Exemplo: uma página de e-commerce, onde os produtos são carregados dinamicamente.

Caminho de uma Requisição na Web

  1. O usuário acessa uma página utilizando o navegador.
  2. O navegador envia uma requisição ao servidor.
  3. O servidor recebe e processa a requisição.
  4. Se necessário, o servidor consulta um banco de dados.
  5. O servidor prepara a resposta com as informações solicitadas.
  6. A resposta é enviada de volta ao navegador.
  7. O navegador interpreta o conteúdo e exibe a página para o usuário.
